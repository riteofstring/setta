What can a section contain?
- Modules
- Object collections
- Parameter collections
- Collection of collections/modules

A section cannot contain:
- A single object
- A single parameter


To determine searchable items:

function findDescendantsByType(allCodeInfo, rootId, type):
   output = []
   idStack = [rootId]
   while (idStack.length > 0){
      currInfo = allCodeInfo[idStack.pop()]
      if(currInfo.type === type){
         output.push(currInfo)
      }
      idStack.push(...currInfo.children)
   }
   return output
