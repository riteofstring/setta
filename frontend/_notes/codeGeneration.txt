// Assign every ~V, ~O, and ~P to a global variable namespace
// When creating a variable, create its children variables and keep track of those variables, i.e. make a tree of the variables
// The code starts with all necessary imports, and then creates variable assignments doing a bottom-up traversal of the tree

// if it's a string, number, boolean, or null, then the var has no children
// if it's an object, then the number of children is the number of keys in the object
// if it's an array, then the number of children i

#6 Object

JSON:
"V~Model": {"P~dog": "fluffy", "P~apple": 9}
Python:
abc = "fluffy"
def = 9
Model = {"dog": abc, "apple": def}

During codegen, Model has 2 children, abc and def, and we store the knowledge that Model is a dict.

JSON:
"P~Model": {"P~dog": "fluffy", "P~apple": 9}
Python:
abc = "fluffy"
def = 9
ghi = {"dog": abc, "apple": def}

During codegen, ghi has 2 children, abc and def, and we store the knowledge that ghi is a dict.

JSON:
"O~Model": {"P~dog": "fluffy", "P~apple": 9}
Python:
abc = "fluffy"
def = 9
ghi = Model(dog=abc, apple=def)

During codegen, ghi has 2 children, abc and def, and we store the knowledge that ghi is a callable.

or 

abc = "fluffy"
def = 9
ghi = {"dog": abc, "apple": def}
jkl = Model(**ghi)

During codegen, ghi has 2 children, abc and def, and we store the knowledge that ghi is a dict.
During codegen, jkl has 1 child, ghi, and we store the knowledge that ghi is a callable.
