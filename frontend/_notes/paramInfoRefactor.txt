A section has to know what is in its main combobox. This can be represented as text.

selectedItem: "torchvision.models.resnet101"

sectionId -> "torchvision.models.resnet101" -> ["download", "pretrained", "verbose"]


paramCollectionId, paramName, defaultVal
1234, "download", ...
1234, "pretrained", ...
1234, "verbose", ...


------------------

Entered values currently map from paramInfoId -> value.
What we really want is string -> value, where string identifies the parameter.

Example:

"(torchvision.models.resnet101, download)" -> True

or

"torchvision.models.resnet101" -> "download" -> True

on the frontend this would be:

paramInfos.x[collectionId]["torchvision.models.resnet101"]["download"] -> 

In the db:

collectionId, objName, paramName, value

or

EVCol
collectionId, objName, paramValuesId
1234, ""torchvision.models.resnet101", 5678


EV
paramValuesId, paramName, value
5678, "download", True
