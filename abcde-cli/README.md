# abcde-cli

Installation:

Make sure conda is not activated:

```
conda deactivate
```

By default, conda activates its base environment when you open a terminal. You can turn this off by doing:
```
conda config --set auto_activate_base false
```


Then run:
```
. ./init_env.sh
```

To deactivate the python environment
```
deactivate
```

To activate
```
. ./activate.sh
```
