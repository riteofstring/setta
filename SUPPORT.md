# Getting support

Start with the [frontend API](packages/workspace/README.md), [browser pipeline guide](packages/workspace/BROWSER.md),
or [Go library guide](packages/local-backend/README.md). For the example apps, use their README and command help:

```sh
setta <app> --help
```

For a reproducible Setta bug, open a bug report and include the Setta version, operating system,
affected library or example app, expected result, and minimal reproduction. Remove credentials and private project
data from logs or examples.

Use a feature request for product ideas. Questions about a custom Python project or third-party
library may be outside the project's support scope, but a focused example can still help identify
whether Setta is involved.

Report suspected vulnerabilities privately as described in [SECURITY.md](SECURITY.md).
