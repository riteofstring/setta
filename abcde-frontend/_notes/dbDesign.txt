Hierarchy from the user's perspective:

Folders:
- name
- userId

UIs
- name
- folder: Folders
- sections: SectionCollections
- availableModules: ModuleCollections
- availableParameters: ParameterCollections

SectionCollections
- name
- folder: Folders

ModuleCollections
- name
- folder: Folders

ParameterCollections
- name
- folder: Folders

Selections
- module: Modules
- object: Objects
- folder: Folders

Sections
- name
- variableName (the name that appears in the header of the section)
- sectionId (not the db record id, but the id the section was given in the UI)
- belongsTo: SectionCollections
- children: SectionCollections
- parent: Sections
- availableModules: ModuleCollections
- availableParameters: ParameterCollections

Modules
- name
- belongsTo: ModuleCollections

Objects
- name
- belongsTo: Modules

Parameters:
- name
- object: Objects
- parameterCollection: ParameterCollections

EnteredValues
- parameter: Parameters
- value
