Things people might want to change in a multi-run
- Value in the combobox
- Values in the params
- Entered value collection
- "Active" sections

=======================================

Wasy to specify a multi-run:


1. GUI
We could do this for each section or for the project as a whole.
The GUI let's you specify the value in the combobox, and for each value in the combobox, you can set multiple values per param.
For example:

```
combobox val 1
    arg 1
        val 1
        val 2
        val 3
    arg 2
        val 1
        val 2

combobox val 2
    arg 1
        val 1
```

Or just arg values for the current combobox value:
```
arg 1
    val 1
    val 2
    val 3
arg 2
    val 1
    val 2
```

Or different entered value collections:
```
evCol1
evCol2
evCol3
```


2. Code section (like Var Control)
The user writes javascript code that returns a list of objects. 
Each object specifies combinations of values that override the existing config.
The purpose of this is to allow the user to specify very specific combinations.

We could render the generated list underneath the code section, and make it so that
you can hover/click on each object to see what that configuration looks like.


=======================================

"Run Group" section

One issue with this is sections that depend on each other.
For example, the "algorithm" section makes a reference to the "dataset" section.
If in a Run Group, "dataset" is de-selected, what should happen to the references to it?

Should there just be 1 Run Group section, with different versions?

The version of Run Group can be specified in the Param Sweep section.
