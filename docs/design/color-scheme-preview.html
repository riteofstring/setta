Setta — proposed color scheme

Eight OKLCH accents anchored to the Setta logo cyan (213°) and the slate-blue neutral ramp (263°). Color is used semantically: violet = agent activity, blue = links/selection, green/amber/red = git + status, teal = metadata/untracked, magenta = attention. Neutrals and the brand cyan are unchanged from the current scheme.
