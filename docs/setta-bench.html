Deliberately bounded

The run matrix grows without making Build harder to read.

Implementation sections keep ordinary scalar defaults. Finite fixed, grid, and paired overrides live in Run setup because they belong to one launch—not to the experiment graph. An optimizer such as Optuna stays outside the focused first version.

Authored workspace

Five sections stay recognizable.

Each added implementation adds one standard code section. Example rows and launch configurations never become canvas nodes, and Bench does not ask the user to wire its fixed data flow.

1 Pass criteria section · the same 4 checks for every run
1 Run setup pane · 10 launch configurations
