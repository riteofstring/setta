The operating loop

Freeze reality. Change one thing. Explain the difference.

Bench is not an agent builder or a leaderboard. It turns the exact state around a consequential run into reproducible, reviewable evidence.

01 / FREEZE

Capture the run boundary

Preserve the case, source revisions, agent profile, model, prompt, permissions, and MCP tool allowlist as one snapshot.

casecontext snapshotagent config
02 / REPLAY

Declare one counterfactual

Fork from an immutable run, alter one source or control, and preserve lineage while the agent executes again.

one deltasame toolssame task
03 / DECIDE

Compare behavior, not just scores

Align events, tool calls, output, usage, timing, and artifacts; then record why the behavioral change should be accepted.

aligned traceAI Followdecision

The thesis

When an agent changes its mind, keep enough state to know why.

Bench earns the canvas by joining real context, immutable execution, source-level attention, and a durable human decision in one inspectable place.
