01 / BUILD

Describe the comparison

10 cases→2 candidates

A case edge means “run every case with this candidate.” A check edge means “apply this same check set to every output.”

02 / RUN

Expand the matrix

10 cases × 2 candidates = 20 executions

One launch creates one immutable run per candidate. With concurrency two, at most two case processes run at once.

Compare finds the matching case ID in two completed runs, then places their artifacts, measurements, and findings side by side.

Deliberately bounded

Bench owns one small comparison loop.

Candidates come from code the user already has. Bench freezes a small launch, runs it locally, and retains just enough evidence for a useful pairwise review.
