Author concepts, not trials

96 labeled pairs→3 code candidates

Deliberately bounded

The matrix can grow without turning Bench into an optimizer.

Fixed, grid, and zipped values are finite launch plans attached to readable candidates. Bench expands exactly what the user can see; an adaptive search engine such as Optuna remains an optional future strategy rather than the product's center.
