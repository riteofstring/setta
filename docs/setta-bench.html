The operating loop

One experiment, four deliberate moves.

Bench keeps mutable experiment design separate from immutable execution history. Every launch freezes what will run before work begins.

01 / BUILD

Compose

Arrange candidates, cases, configurations, and evaluators into one legible experiment.

02 / RUN

Execute

Preview the matrix, freeze its provenance, then run with bounded concurrency.

03 / COMPARE

Inspect

Align metrics, failures, logs, documents, media, and representative disagreements.

04 / DECIDE

Replay or promote

Reproduce an exact run, fork one explicit change, or promote a trusted baseline.

Clear ownership

Bench coordinates the evidence layer.

It does not replace the tools that author code, resolve configuration, or optimize trials. It gives their work one durable operational and review surface.

Inputs and planners

Existing tools keep their authority.

Bench consumes explicit, revision-bound outputs rather than importing sibling internals.
