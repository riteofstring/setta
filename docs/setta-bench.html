01 / BUILD

Author concepts, not trials

96 labeled pairs→3 code candidates

Each candidate is only runnable code. Separate parameter-plan sections bind named values to the code that varies, producing ten launch variants without duplicating implementations.

02 / RUN

Expand the matrix

96 cases × 10 variants = 960 executions

One launch creates one immutable run per resolved variant. The exact parameter values are frozen with each run; concurrency four bounds local CPU use.

Deliberately bounded

The matrix can grow without turning Bench into an optimizer.

Fixed, grid, and zipped values live in finite Parameter Plan sections connected to readable code. Bench expands exactly what the user can see; an adaptive search engine such as Optuna remains an optional future strategy rather than the product's center.
