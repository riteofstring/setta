The intervention loop

Pause at consequence. Decide in context. Resume with proof.

The originating app still owns the agent and execution. Workspace contributes a coherent review surface at the moment human authority matters.

01 / SURFACE

Bind the request to real material

The paused event names exact arguments, affected resources, diffs, risk signals, and the run that requested them.

tool previewaffected filesrun event
02 / DECIDE

Grant only intended authority

A reviewer can reject, approve unchanged, or narrow typed arguments without rewriting the agent's plan.

approverejectnarrow
03 / RESUME

Continue the same run

The decision becomes a persisted event. Execution receives only the granted arguments and returns its result to the existing trace.

receipttool resultlineage
Same capability · three compositions

Intervention appears where the work already lives.

A queue pane joins the full shell, one intervention can open through the standard standalone section surface, and the resumed run returns to a managed window. There is no second orchestration UI.

Capability boundary

The authority boundary belongs inside the originating app.

Agent Intervention adds one durable review model and consistent Workspace compositions. It does not become an execution platform merely because an agent paused.

Provided by Workspace

Consistent review composition

Queue pane, attention, Inspector controls, standalone section surface, saved views, and managed windows.

registered intervention sectionaffected-section attentionfocused and in-context views
Owned by the host app

Run and authorization lifecycle

Python Canvas or Bench owns the paused agent, policy, persistence, tool execution, and continuation.

exact requested + granted argumentsapprove · reject · narrowdecision receipt in run history
Deliberately excluded

No Setta Runbook

No authored DAGs, schedules, retries, credential vault, remote workers, deployment engine, or general infrastructure orchestration.

no workflow authoringno schedulerno execution backend
The thesis

Capable agents need visible limits more than static flowcharts.

Intervention makes consequential intent inspectable at the point of action while leaving planning and execution where they already belong.
