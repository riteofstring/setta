Product rule

Any producer prepares the material. People inspect the consequential shape.

Codex, Claude Code, OpenCode, scripts, other applications, or people can create the same file-based inputs. Setta does not host their execution loop: judgment happens in a visual Workspace, then the result leaves as a compact artifact another tool can consume.

01 / INGEST

Accept producer-neutral material

Review requests and editable context bundles arrive as ordinary files without requiring a person to retype them.

Review or author visually

Review preserves the submitted request while recording a response. Context Pack intentionally edits a new bundle revision.

Export a durable boundary

Both apps emit small, versioned artifacts rather than trapping useful results in a dashboard or conversation transcript.

Design direction

The workflow changes. The Workspace muscle memory does not.

Review changes presentation to match the decision. Context Pack changes presentation to match the source. Both remain recognizably Setta and finish with portable artifacts.
