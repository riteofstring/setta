Product rule

Any producer prepares the material. People inspect the consequential shape.

Codex, Claude Code, OpenCode, scripts, other applications, or people can create the same file-based inputs. Setta does not host their execution loop: judgment happens in a visual Workspace, then the result leaves as a compact artifact another tool can consume.

Shared implementation boundary

Four applications, not four design systems.

The differentiator lives in a few custom section bodies and portable schemas. Navigation, canvas behavior, graph semantics, inspection, attention, saved views, and window management remain Workspace-owned.

Design direction

The app changes. The Workspace muscle memory does not.

Each concept earns its UI by making evidence, scope, visual choice, or risk easier to see—then gets out of the way with an exportable result.
