## Evidence and playback

The AI training-program demonstration includes genuine corrective turns. Its
help/dry-run tools run in the historical workspace; the exact saved file also
passes a separate Runpod PyTorch check. Workflow shots show two completed model
reviews from the same run, separated by a cut that removes waiting and a native
refresh. The semantic graph is authored research data; Setta 3's workflow is a
validated draft. Setta 4's report is a built-in example.

Python Canvas fits the original synthetic Model Workshop problem. Realtime’s webpage demonstration changes
a drawing and runs its original Signal Bloom handlers. The film's short excerpts
are supported by the longer clips and numerical evidence in the walkthroughs.
The short film holds Realtime’s native final poster after its original capture ends.
The Setta 4 report plays at 65% speed to leave reading time; other speeds and exact
crops are recorded in the authoritative film edit list.

All historical builds, runtimes and browser execution use OVH and Runpod. Local
editing and rendering use captured pixels. Full recordings, application state and
source references remain preserved. The web copy is a smaller encode of the same
1080p master.
