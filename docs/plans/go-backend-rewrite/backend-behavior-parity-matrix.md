## Status Meanings

- `Proved`
  - the surviving behavior is backed by cited Go implementation and cited Go
    proof.
- `Implemented, proof incomplete`
  - Go code appears to implement the behavior, but the current proof does not
    yet match the source-baseline evidence closely enough.
- `Missing`
  - the source-baseline behavior does not currently have an equivalent Go
    behavior.
- `Dormant / unproven caller`
  - the source-baseline behavior exists, but this matrix slice does not yet
    prove that a direct Go equivalent is still required by active callers or
    by the current Go architecture.
- `Intentional divergence`
  - the source-baseline behavior changed on purpose, and the rewrite docs or
    active-caller contract explicitly document the clean break.

## Current Read

- The first audited slice already shows why the broader rewrite checklists were
  not enough.
- Most audited lifecycle, route, metadata, and websocket behaviors are now
  proved.
- Several format-rule clusters are implemented in Go but still under-proved
  relative to `main`.
- Ten concrete parity gaps are already visible:
  - source-baseline `add_kwarg` creates unnamed editable params
  - current Go `AddKwarg` assigns a non-empty generated name instead
  - source-baseline `saveAsNewProjectConfig` changes behavior based on
    `withRefs`
  - current Go ignores `withRefs` and always performs the same clone path
  - source-baseline prompt-template updates refresh linked prompt-section
    cached state
  - current Go does not run an equivalent linked-section refresh
  - source-baseline prompt-template delete blocks workflow-edge references
    with `409`
  - current Go deletes referenced workflow templates without that guard
  - source-baseline engine-config create/update accepts blank names when the
    field is present
  - current Go trims and rejects blank engine-config names
  - source-baseline listener registration changes push
    `ListenerCoverageSnapshot` updates over the frontend websocket
  - current Go only exposes the pull route and does not emit the websocket
    update
  - source-baseline listener transport supports `use_temporary_ids`
  - current Go rejects temporary listener ids on `ListenerInit`
  - source-baseline file-browser folder listings show dev-facing dotfiles by
    default
  - current Go hides all dotfiles unless callers opt in with `includeHidden`
  - source-baseline share-scope UI-setting reveal routing is constrained to the
    active `shareSessionId`
  - current Go reveal routing ignores share-session scope and treats frontend
    selection globally
  - source-baseline reveal-path routing returns the same allowlist `400` for
    missing paths outside approved roots
  - current Go reveals leak `404 path_not_found` before the allowlist check on
    those missing outside-root paths
- The prompt-template slice also shows one documented transport divergence
  (`GET /getPromptTemplates` narrowed to IDE mode) and one broader realtime
  defer decision (`PromptTemplatesUpdated` / watcher refresh), while the
  linked-template runtime/codegen source-of-truth path itself is proved.

  - two source behaviors that are now dormant or still unproven as active

- The detached-run slice mostly closes with proofs and adds one more edge-case
