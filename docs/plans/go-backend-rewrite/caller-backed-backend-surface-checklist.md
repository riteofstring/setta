# Caller-Backed Backend Surface Checklist

Snapshot date: 2026-03-12.

Primary agent entrypoint: `docs/plans/go-backend-rewrite/CURRENT.md`.

Audit/maintenance plan:
`docs/plans/go-backend-rewrite/caller-backed-backend-surface-checklist-audit-plan.md`.

Companion broad-coverage inventory:
`docs/plans/go-backend-rewrite/backend-capability-coverage-checklist.md`.

Use this checklist to answer:
"Does the active caller reach a Go-owned backend surface today?"

This is a current-caller inventory, not a route-for-route Python parity list.
Together with the ownership checklist, this doc is the rewrite progress
tracker. File deletion is not the tracker while Python source is being retained
for mergeability.

Status meanings:

- `Complete`: the current caller reaches a registered Go transport backed by a
  Go-owned runtime.
- `Partial`: Go owns a bounded slice, but the current caller still hits a
  documented limitation or follow-up boundary.
- `Missing`: the current caller still depends on Python, or no Go-owned
  equivalent exists yet.

Internal Go capability does not count as `Complete` unless the active caller
actually reaches that Go-owned transport/runtime today.

Primary sources used for this checklist:

- `docs/plans/go-backend-rewrite/go-backend-rewrite-plan.md`
- `backend/setta/types/routes.py`
- `backend/setta/routers/*.py`
- `frontend/src/utils/generatedEndpoints.ts`
- non-test `frontend/src/**` caller sites, including direct websocket callers
- current Go transport/runtime packages under `internal/`

## Bottom line

For the current clean-break rewrite scope, the active Go backend owns most of
the product-facing surface that current callers use:

- auth/modes/settings
- project shell and current project-state transport
- listener coverage and force-refresh plus the replacement websocket/terminal runtime
- LSP/watch-code
- MCP/tooling
- deployments/launcher/workspace launch
- plugins
- git/file browser/artifacts
- current agentic, app-gen skills, and transcription surfaces

The remaining gaps are concentrated in older Python-only route tails,
intentionally bounded AI/plugin behavior, and dormant detached-run/CLI-output
transport. The old `loadAvailableArtifacts` helper no longer has a reachable
frontend caller in this worktree and should be treated as dormant route-enum
residue, not active rewrite surface.

Treat the active caller-backed gaps as remaining rewrite surface, not as
historical noise.
