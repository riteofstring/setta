A read-only player for recorded experiments

Turn experiment results into a mini-app.

A script or agent runs trials anywhere. Setta maps the recorded factors to controls, so choosing one real trial changes every result section together. It does not launch, rerun, or predict experiments.

Where it fits

Not another experiment tracker.

TensorBoard, W&B, and MLflow differ substantially, but they already cover the overlapping job of collecting and organizing runs. Experiment Lens is only useful when a generic run page is not the clearest way to understand the result.

The bet is composability, not a missing chart Existing tools already show images, tables, text, and custom charts. The defensible difference is a portable, domain-shaped workspace. If that view is not materially clearer, use the tracker.
Question TensorBoard / W&B / MLflow Experiment Lens
Primary job Track, compare, and manage runs over time. Play back one bounded experiment as an interactive mini-app.
Interface General-purpose charts, tables, reports, artifact browsers, and—in W&B—custom panels. Domain-specific Setta sections such as images, diffs, plans, maps, code, and traces.
Interaction Select or filter runs, update dashboard panels, inspect history, and sometimes launch sweeps. A manifest binds a recorded factor combination to an entire composed Setta workspace.
Data boundary Product-specific logging SDK, event files, or tracking backend. Portable manifest plus artifact references; it can be produced from a tracker export.
Scale and cost Mature integrations and generic views make large run histories economical. A bounded trial set with extra section composition; not worth it for ordinary scalar experiments.
Strongest at Monitoring, long histories, large run sets, collaboration, and lineage. Human understanding of rich, coordinated outputs and a clean handoff to another tool.
Does not own Varies by product; often much of the experiment lifecycle. Running jobs, tuning, storage, model registry, or agent orchestration.

Use the existing tracker when…

Curves, scalar comparisons, tables, and its artifact viewer already answer the question clearly.

Use Experiment Lens when…

Several domain-specific artifacts must change together for a human to see why one recorded trial behaves differently.

Portable by design

The app owns the view, not the experiment runner.

Codex, Claude, OpenCode, a notebook, or a CI job can produce the same small input. The result can leave Setta just as easily.
