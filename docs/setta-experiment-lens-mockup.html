Setta Experiment Lens
Examples Scope Handoff
A focused reference app for recorded experiments

Explore the shape of an experiment, not just its charts.

An agent or script writes a manifest and artifacts. A trusted local project supplies checked-in Setta sections, and Lens links them through shared selection and timeline state. It neither generates the interface nor runs the experiment.

Explore two presentations See the scope

A small demo contract

DATA
The manifest supplies recorded data Stable observation IDs, factors, metrics, and artifact references.
VIEW
The trusted project supplies the views Checked-in sections share filters, selection, and timeline state.
OUT
A selection packet leaves the app No runner, tracker, dashboard DSL, or dynamic plug-in system.

Scope of the reference app

            

              Trackers record runs. Lens demonstrates linked exploration in
              Setta.
            

            

              Lens is not trying to replace TensorBoard, W&B, MLflow, or a
              one-off notebook. It is a focused example of how trusted
              project-local sections can make recorded results explorable and
              hand a precise selection to the next tool.
            

          

          

            

              
Question

              
Experiment systems

              
This Setta reference app

            

            

              
Primary object

              
Run, metric, artifact, lineage

              

                A trusted project presentation and portable selection
              

            

            

              
Exploration model

              
Generic dashboards, queries, panels

              

                Checked-in sections shaped around this experiment’s
                  domain
              

            

            

              
Customization

              
Built-in panels, notebooks, or plug-ins

              

                Ordinary trusted project code; no generated UI or dynamic
                  discovery
              

            

            

              
Selecting an outlier

              
Opens run details and logged artifacts

              

                Updates every linked native section to the same exact
                  observation
              

            

            

              
Rich outputs

              
Usually files or tracker-specific panels

              

                Code, diffs, images, drawing, spreadsheets, browser views,
                  terminals, and custom sections
              

            

            

              
Execution

              
Often logs or orchestrates runs

              

                Read-only: references results made by any script, harness, or
                  platform
              

            

          

        

      


      

        

          

            
The handoff

            
A selection is useful outside the app.

            

              The Lens exports IDs, filters, time ranges, annotations, and
              artifact references—not screenshots of a dashboard. Another Setta
              app, notebook, CLI, or agent can continue from the same evidence.
