# Security policy

## Supported versions

Security fixes are made on the latest released version. Pre-release builds and older releases may
receive a fix only when maintainers decide that a backport is practical.

## Reporting a vulnerability

Use **Report a vulnerability** on the repository's Security page to contact the maintainers
privately. Do not open a public issue or include sensitive project data, credentials, or an active
exploit in a public discussion.

Include the affected Setta version and platform, the impact, reproduction steps, and any suggested
mitigation. The maintainers will acknowledge the report, assess affected behavior, and coordinate
disclosure and a release when a fix is needed.

If private vulnerability reporting is unavailable, contact a maintainer privately using the
contact information on their GitHub profile before sharing details.
